# LinguaKids

เว็บแอปฝึกภาษาอังกฤษสำหรับเด็กอนุบาลถึงประถม — ฝึกคำศัพท์ ฟัง พูด อ่าน
ด้วยเกมและเพื่อน AI ที่คุยโต้ตอบด้วยเสียงได้

> **สถานะปัจจุบัน: เฟส P2 เสร็จแล้ว** — 67 ด่านบนคลังคำ 290 คำ 29 หน่วย (Pre-A1 และ A1)
> เล่นได้ 4 โหมด: จับคู่คำ · ฟังแล้วเลือกภาพ · ดูภาพเติมคำ · เติมคำในประโยค
> พร้อมระบบทบทวนอัตโนมัติ ดาว XP และไฟต่อเนื่อง
> และคุยกับเพื่อน AI ที่ตอบกลับทั้งข้อความและเสียงได้ที่ `/chat`
> พร้อมด่านทบทวนรายวันที่ `/review` ซึ่งหยิบคำที่กำลังจะลืมมาให้ตามตาราง FSRS
>
> ยังขาด: เสียงพูดเข้า (ไมค์) · บัญชีผู้ใช้

## เริ่มพัฒนา

```bash
npm install
npm run dev
```

เปิด <http://localhost:3000> สำหรับหน้าแรก และ <http://localhost:3000/styleguide>
สำหรับดู component ทั้งหมด

คำสั่งอื่น

```bash
npm run build      # build โปรดักชัน
npm run typecheck  # ตรวจ type ทั้งโปรเจกต์
npm run lint       # ESLint
```

## ตัวแปรสภาพแวดล้อม

คัดลอก `.env.local.example` เป็น `.env.local` แล้วเติมค่า

- `GEMINI_API_KEY` — จำเป็นเฉพาะหน้า `/chat` ขอได้ฟรีจาก Google AI Studio
  ถ้าไม่ใส่ ด่านทั้งหมดยังเล่นได้ปกติ แต่แชทจะขึ้นข้อความบอกว่ายังไม่ได้ตั้งค่า
- เสียงอ่านใช้ Web Speech API ของเบราว์เซอร์ จึงไม่ต้องใส่ค่าอะไร

## หลักการที่ยึดในโค้ด

- ตรรกะการให้คะแนนทั้งหมดเป็น **ฟังก์ชันบริสุทธิ์** ใน `src/lib` แยกจาก React และ store
  จึงเทสได้ตรง ๆ และย้ายไปฝั่งเซิร์ฟเวอร์ได้ตอนมีฐานข้อมูลโดยไม่ต้องเขียนใหม่
- การสุ่มทุกจุดที่มีผลต่อหน้าจอใช้ seed คงที่ ไม่ใช้ `Math.random` ตรง ๆ
- component ไม่อ่านนาฬิกาเอง ชั้น store เป็นคนประทับเวลาให้
- API key อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น มีเทสเดินไฟล์จริงคอยกันไม่ให้ client
  เผลอ import ชั้นที่แตะ key (ดู `src/lib/ai/boundary.test.ts`)
- ไม่อ่านนาฬิการะหว่าง render เลย ใช้ `useNow()` ซึ่งคืน null ฝั่งเซิร์ฟเวอร์
  เพราะหน้าถูกสร้างไว้ล่วงหน้าตอน build ซึ่งไม่ใช่วันที่เด็กเปิดหน้า
- ความยากของข้อมาจากดาวความชำนาญของ **คำนั้น** ไม่ใช่ระดับรวมของเด็ก
  คำที่เพิ่งเจอจึงยังมีตัวเลือกให้ ส่วนคำที่คุ้นแล้วต้องเขียนเอง ในด่านเดียวกัน

## กฎการออกแบบที่ยึดไว้

1. ทุกข้อความบนจอต้องกดฟังเสียงได้ เพราะเด็กอนุบาลยังอ่านไม่ออก
2. ตอบผิดไม่ลงโทษ — เป็น "ลองอีกครั้ง" พร้อมเฉลยแบบสอน
3. หนึ่งหน้าจอทำหนึ่งอย่าง
4. เซสชันละ 3–7 นาที แล้วปิดด้วยรางวัล
5. ภาษาไทยช่วยตอนต้น แล้วถอด scaffold ออกตามระดับ
6. สถานะถูก/ผิดต้องไม่สื่อด้วยสีเพียงอย่างเดียว (เด็กตาบอดสี)
7. พื้นที่แตะขั้นต่ำ 44×44 px และเล่นด้วยคีย์บอร์ดได้ทั้งหมด
