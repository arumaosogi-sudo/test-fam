# ADR-0004 — เขียน UI component เองสำหรับหน้าจอเด็ก ยังไม่ใช้ shadcn/ui

วันที่: 1 พ.ย. 2026 · สถานะ: ใช้อยู่ (ต่างจากที่เขียนไว้ใน PLAN.md ตอนแรก)

## บริบท

แผนเดิมระบุ shadcn/ui แต่ component ของ shadcn ออกแบบมาสำหรับแอปธุรกิจ
คือเรียบ บาง เงาน้อย ขนาดกะทัดรัด ซึ่งตรงข้ามกับที่หน้าจอเด็กต้องการ
(ปุ่มใหญ่ ขอบหนา กดแล้วยุบ มุมโค้งมาก พื้นที่แตะกว้าง)

ถ้าเอา shadcn มาแล้ว override แทบทุกคลาส จะเหลือแต่ความซับซ้อนโดยไม่ได้ประโยชน์

## การตัดสินใจ

- หน้าจอฝั่งเด็กใช้ component ที่เขียนเองใน `src/components/ui/`
  แต่วางโครงตามแบบแผนเดียวกับ shadcn (cva + `cn()` + prop `variant`/`size`)
- ยังเปิดทางให้เพิ่ม shadcn ทีหลังสำหรับ **แดชบอร์ดครู** (ภารกิจ E6) ซึ่ง
  ต้องใช้ตาราง dialog และ dropdown ที่เขียนเองไม่คุ้ม

## ผลที่ตามมา

- ควบคุมหน้าตาได้เต็มที่และ bundle เล็กลง
- ต้องดูแล accessibility เองในส่วนที่ shadcn (Radix) เคยจัดการให้ เช่น
  focus trap ของ dialog — เมื่อถึงจุดที่ต้องใช้ ให้ติดตั้ง Radix เฉพาะส่วนนั้น
