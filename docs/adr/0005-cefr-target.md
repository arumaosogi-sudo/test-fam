# ADR-0005 — เป้าหมายระดับภาษา: เป้าของเด็ก A1→B1 บนบันไดที่ไต่ได้ถึง C1

วันที่: 1 พ.ย. 2026 · สถานะ: ใช้เป็นค่าเริ่มต้น (รอการยืนยัน — ข้อตัดสินใจ D1)

## บริบท

โจทย์ตั้งต้นระบุว่าต้องการให้เด็ก "พูดและสื่อสารได้ในระดับ C1"
แต่ C1 คือระดับที่ใช้ภาษาเชิงวิชาการและวิชาชีพได้คล่อง ซึ่งเด็กอายุ 12 ปี
แทบไม่มีระบบไหนพาไปถึงได้ถ้าไม่ใช่โรงเรียนอินเตอร์แบบ immersive เต็มเวลา

การตั้งเป้าที่เป็นไปไม่ได้มีราคาที่ต้องจ่าย: เนื้อหาจะยากเกินวัย เด็กท้อ
และถ้านำไปเสนอผู้ปกครองด้วยคำโฆษณานี้ก็จะเป็นการให้ความหวังที่ผิด

## การตัดสินใจ

แยกสองเรื่องออกจากกัน

| | เป้าหมาย |
|---|---|
| เป้าของตัวเด็ก | อนุบาล Pre-A1 · ป.1–2 A1 · ป.3–4 A2 · ป.5–6 A2+/B1 |
| เป้าของตัวระบบ | บันไดระดับและ engine รองรับถึง C1 ไม่มีเพดาน |

`CEFR_LEVELS` ใน `src/components/ui/level-badge.tsx` จึงมีถึง C1 ตั้งแต่วันแรก
แม้เนื้อหา B2–C1 จะยังไม่ถูกสร้างในเฟสแรก

## ผลที่ตามมา

- เด็กที่เก่งกว่าวัยเรียนล่วงหน้าได้ ไม่ติดเพดาน
- ระบบใช้ต่อกับ ม.ต้น–ม.ปลาย ได้โดยไม่ต้องรื้อโครงสร้าง
- ถ้าเจ้าของโปรเจกต์ยืนยันเป้า C1 ที่ตัวเด็ก ต้องแก้ ADR นี้ และขยาย
  แผนเนื้อหากับ placement test ให้ละเอียดกว่าเดิมมาก
