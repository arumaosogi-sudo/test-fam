# ADR-0006 — ใช้ Gemini เป็นโมเดลภาษา และเลือกรุ่นจากที่วัดจริง

วันที่: 2 พ.ย. 2026 · สถานะ: ใช้อยู่ · แทนที่ข้อสันนิษฐานเดิมใน PLAN.md ที่เขียนว่าใช้ Claude

## บริบท

แผนเดิมเขียนไว้ว่าโหมดแชทจะเรียก Claude แต่ยังไม่ทันได้เขียนโค้ด
เจ้าของโปรเจกต์เลือกใช้ Gemini แทนเพราะมีโควตาฟรี ซึ่งสำคัญกับโปรเจกต์
ที่ยังไม่มีรายได้และต้องให้เด็กคุยได้ไม่จำกัดจำนวนครั้ง

## การตัดสินใจ

**1. ซ่อนผู้ให้บริการไว้หลัง interface** — `ChatProvider` ใน `src/lib/ai/types.ts`
โค้ดแชทเรียกผ่าน `getChatProvider()` เท่านั้น หลักการเดียวกับ ADR-0003
เราเปลี่ยนเจ้าไปแล้วหนึ่งครั้งตั้งแต่ยังไม่เขียนโค้ด และคงเปลี่ยนอีกเมื่อ
ราคาหรือโควตาเปลี่ยน

**2. รุ่นหลัก `gemini-3.1-flash-lite` รุ่นสำรอง `gemini-3.5-flash`**

วัดด้วย prompt จริงบนโควตาฟรี 1–2 พ.ย. 2026:

| รุ่น | เวลาตอบ | ผล |
|---|---|---|
| `gemini-3.1-flash-lite` | ~1.0–1.3 วิ | 200 ทุกครั้ง |
| `gemini-3.5-flash` | ~2.8–3.9 วิ | 200 ทุกครั้ง |
| `gemini-3.8-flash` | 12 / 118 / 14 วิ | 503 บ่อย |
| `gemini-flash-latest` | timeout 25 วิ | 503 |
| `*-flash-lite` รุ่น 3.5 ขึ้นไป | — | 400 invalid argument |

รุ่นใหม่ที่สุดใช้กับเด็กไม่ได้เลยบนโควตาฟรี เด็กอนุบาลรอ 12 วินาที
ไม่ไหว บทสนทนาตายก่อน เราจึงเลือกตัวที่เร็วและนิ่งเป็นหลัก แล้วถอยไป
ตัวที่ฉลาดกว่าเมื่อตัวหลักล่มหรือตอบผิดรูปแบบ แทนการขึ้น error ให้เด็กเห็น

**3. ไม่สตรีมคำตอบ** — ต่างจากที่ PLAN.md เขียนไว้ว่าใช้ SSE

เพราะทุกเทิร์นต้องได้ JSON ที่มีคำแปลไทย คำที่เด็กใช้ผิด และตัวเลือกตอบ
ครบทั้งก้อน (ดู PLAN.md หัวข้อ 10) การสตรีม JSON ที่ยังไม่ปิดวงเล็บ
ต้องเขียน parser แบบ incremental เอง ซึ่งแลกความซับซ้อนนั้นกับการ
ประหยัดเวลาแค่ราวหนึ่งวินาทีไม่คุ้ม — คำตอบของ Milo ยาว 1–2 ประโยคเท่านั้น

เมื่อถึง P3 ที่ต้องป้อนเสียงเข้า TTS ทีละประโยคเพื่อให้ทันเป้า < 1.5 วิ
ค่อยกลับมาทบทวนข้อนี้

**4. schema ที่ส่งให้โมเดลสร้างจาก zod ตัวเดียวกับที่ใช้ตรวจขากลับ**

`z.toJSONSchema()` แล้วตัดคีย์ที่ Gemini ไม่รองรับออก (`toGeminiSchema`)
ถ้าเขียน schema ให้โมเดลด้วยมืออีกชุด สองชุดจะหลุดจากกันวันที่ใครเพิ่มฟิลด์

## ผลที่ตามมา

- เปลี่ยนผู้ให้บริการ = แก้ `src/lib/ai/index.ts` กับเขียน provider ใหม่หนึ่งไฟล์
- ตารางรุ่นด้านบนจะเก่า รุ่นใหม่ออกเรื่อย ๆ และโควตาฟรีเปลี่ยนได้ตลอด
  มี `src/lib/ai/gemini.live.test.ts` ไว้ยิงของจริงเพื่อวัดซ้ำ
  (`RUN_LIVE_AI=1 npx vitest run gemini.live`)
- เทสปกติไม่แตะเน็ต จึงไม่จับกรณีที่ Gemini เปลี่ยนรูปแบบคำตอบหรือ
  เลิกรองรับรุ่นที่เราใช้ ต้องรัน live test เป็นระยะ
- โควตาฟรีมีลิมิตต่อนาทีและต่อวัน ถ้ามีผู้ใช้จริงหลายคนพร้อมกันจะชนเพดาน
  ต้องย้ายไปบัญชีแบบจ่ายเงินหรือทำคิวก่อนเปิดใช้จริง
