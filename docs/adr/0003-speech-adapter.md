# ADR-0003 — แยกชั้น adapter สำหรับบริการเสียงตั้งแต่ต้น

วันที่: 1 พ.ย. 2026 · สถานะ: ใช้อยู่

## บริบท

เฟสเดโมใช้ Web Speech API ของเบราว์เซอร์ซึ่งฟรีและไม่ต้องมี API key
แต่มันบอกได้แค่ว่าเด็กพูดออกมาเป็นคำว่าอะไร **ไม่ได้ให้คะแนนราย
หน่วยเสียง** ซึ่งเป็นหัวใจของโหมดฝึกออกเสียง สุดท้ายจึงต้องย้ายไป
Azure Pronunciation Assessment (หรือ Speechace / ELSA)

## การตัดสินใจ

นิยาม interface กลางไว้ก่อนใน `src/lib/speech/types.ts`:

- `TtsProvider` — อ่านออกเสียง
- `SttProvider` — ถอดเสียงเป็นข้อความ
- `PronunciationProvider` — ให้คะแนนการออกเสียง พร้อมรายละเอียดราย phoneme

โค้ดเกมเรียกผ่าน `getTts()` ใน `src/lib/speech/index.ts` เท่านั้น
ห้ามเรียก `window.speechSynthesis` ตรงจาก component

## ผลที่ตามมา

- เปลี่ยนผู้ให้บริการ = แก้ `src/lib/speech/index.ts` ไฟล์เดียว
- ต้องยอมรับว่าในเฟสแรกคุณภาพเสียงขึ้นกับเครื่องของผู้ใช้ และบางเครื่อง
  อาจไม่มีเสียงภาษาอังกฤษติดมาเลย — UI จึงต้องรองรับกรณี `isAvailable()`
  คืนค่าเท็จ (ปุ่มลำโพงจะถูก disable พร้อมบอกเหตุผล)
- `PronunciationProvider` ยังไม่มีตัว implement จริง จนกว่าจะตัดสินใจ D2
