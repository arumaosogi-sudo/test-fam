# ADR-0007 — ตรวจคำแปลไทยด้วยพจนานุกรมเปิด แทนการเชื่อคำแปลที่ AI เขียนเอง

วันที่: 2 พ.ย. 2026 · สถานะ: ใช้อยู่

## บริบท

คำแปลไทย คำอ่าน และประโยคตัวอย่างของคลังคำ 120 คำแรก **เขียนด้วย AI ทั้งหมด
และไม่มีใครตรวจ** เป็นหนี้ที่ค้างมาตั้งแต่ P1 (ภารกิจ T106) และเป็นตัวขวาง
การขยายคลังคำไปหลักพัน เพราะถ้าขยายโดยไม่ตรวจ ก็คือเพิ่มคำแปลที่ไม่มีใคร
รับรองอีกหลายพันรายการในสื่อที่เอาไปสอนเด็กจริง

## แหล่งที่พิจารณา

| แหล่ง | ขนาด | สัญญาอนุญาต | ผล |
|---|---|---|---|
| **English Wiktionary** ผ่าน [kaikki.org](https://kaikki.org/) | ทั้ง Wiktionary | CC BY-SA 4.0 (ของ Wiktionary) | ✅ **เลือกอันนี้** |
| [LEXiTRON 2.0](https://huggingface.co/datasets/SEACrowd/lexitron) (NECTEC) | 83,000 รายการ อังกฤษ→ไทย | ระบุว่า "other" ต้องไปอ่านเงื่อนไขเอง | ❌ สัญญาอนุญาตไม่ชัด |
| [Volubilis](https://sourceforge.net/projects/belisan/) | ใหญ่ หลายภาษา | แหล่งที่สามบอกว่า CC BY-SA 4.0 แต่หน้าดาวน์โหลดไม่ได้ระบุ | ❌ ยืนยันไม่ได้ |
| [Thai-English transliteration](https://zenodo.org/records/6570049) | เล็ก | CC BY 4.0 ชัดเจน | ❌ มีแต่คำทับศัพท์ ไม่ใช่คำแปล |

เลือก Wiktionary เพราะเป็นแหล่งเดียวที่ **สัญญาอนุญาตชัดเจน** และ
**ตรวจย้อนได้** — ทุกคำมีหน้าเว็บสาธารณะให้คนตรวจเปิดดูที่มาเองได้
ส่วน LEXiTRON ใหญ่กว่าและเป็นงานของ NECTEC ซึ่งน่าจะเหมาะกับภาษาไทยมากกว่า
แต่เอามาใช้ไม่ได้จนกว่าจะอ่านเงื่อนไขการใช้ซ้ำให้ชัด — ถ้าเงื่อนไขเปิดพอ
ควรกลับมาพิจารณาใหม่เป็นแหล่งที่สอง

## การตัดสินใจ

**1. พจนานุกรมใช้ "ตรวจ" ไม่ใช่ "แทนที่"**

ไม่เอาคำแรกของพจนานุกรมมาทับของเราอัตโนมัติ เพราะพจนานุกรมให้คำที่เป็นทางการ
คำเก่า หรือคำกำกวมบ่อย ๆ ซึ่งไม่เหมาะกับเด็ก ตัวอย่างจริงที่เจอ:

- *cat* → `แมว` กับ `วิฬาร์` (คำหลังเป็นคำเก่า)
- *bad* → `แย่` `เลว` `ชั่ว` (แรงเกินไปสำหรับเด็ก บทเรียนต้องการคู่ตรงข้ามของ ดี)
- *face* → `หน้า` (กำกวม: หน้ากระดาษ / ด้านหน้า / ฤดู)

**2. ทุกคำต้องประกาศที่มาในข้อมูล ไม่ใช่ในความทรงจำ**

เพิ่มฟิลด์ `thSource` บังคับทุกคำ: `wiktionary` / `adapted` / `unverified`
มีเทสกันไม่ให้คำ `unverified` หลงอยู่ในคลัง และกันไม่ให้ `adapted`
ไม่มีเหตุผลเขียนกำกับ — เพิ่มคำใหม่โดยไม่ตรวจแล้วเทสจะพังทันที

**3. ทำเป็นสคริปต์ที่รันซ้ำได้** — `npm run check:thai`

เหตุผลที่ต้องรันซ้ำได้ ไม่ใช่ตรวจครั้งเดียวจบ: เป้าหมายคือขยายคลังคำไปหลักพัน
ถ้าการตรวจเป็นงานมือ มันจะไม่ถูกทำอีกเลยหลังคำที่ 200

## ผลที่ได้รอบแรก

จาก 120 คำ: ตรงกับ Wiktionary ตรงตัว **110 คำ** · ปรับถ้อยคำเองโดยมีเหตุผล **10 คำ**
· ไม่มีคำไหนเหลือเป็น `unverified`

สองอย่างที่การตรวจไปเจอ และคงไม่มีใครเห็นถ้าไม่ได้ตรวจ:

- `me` ถูกกำกับชนิดคำเป็น `noun` ทั้งที่เป็นคำสรรพนาม (เพิ่ม `pronoun` เข้า schema แล้ว)
- รอบแรกของสคริปต์กรองเฉพาะคำแปลที่เป็นคำคุณศัพท์ ทำให้ชื่อสีทั้งสิบ "ไม่ตรง"
  ทั้งที่ตรง — ในไทยชื่อสีเป็นคำนาม (`สีแดง`) Wiktionary จึงเก็บไว้ใต้ noun
  **เครื่องมือตรวจเองก็ต้องถูกตรวจ** ถ้าเชื่อผลรอบแรกจะได้แก้คำแปลที่ถูกอยู่แล้วให้ผิด

## คำอ่าน IPA — ตรวจด้วยวิธีเดียวกันแล้ว

ใช้ `npm run check:ipa` ดึงคำอ่านจาก Wiktionary มาทับของเดิม
**เลือกสำเนียง General American** เพราะเสียงอ่านในแอปตั้งเป็น `en-US`
คำอ่านที่เขียนไว้เดิมปนกันระหว่างสำเนียงอังกฤษกับอเมริกัน (เช่น `/ˈwɔːtər/`
ซึ่งเอาสระแบบอังกฤษมาผสมกับ r ท้ายคำแบบอเมริกัน) ถ้าปล่อยไว้ เด็กจะเห็น
สัญลักษณ์อย่างหนึ่งแต่ได้ยินเครื่องอ่านออกเสียงอีกอย่างหนึ่ง

รายละเอียดอยู่ใน [docs/ipa-review.md](../ipa-review.md)

## สิ่งที่ยังไม่ได้ตรวจ

- **ประโยคตัวอย่าง** — ไม่มีพจนานุกรมไหนตรวจให้ได้ ต้องใช้คนอ่าน
- ตรงกับพจนานุกรมไม่ได้แปลว่าเหมาะกับเด็ก ยังควรมีครูอ่านทั้งชุดอีกรอบก่อนใช้จริง

## เรื่องสัญญาอนุญาตที่ต้องรู้

เนื้อหา Wiktionary เป็น CC BY-SA 4.0 เราจึงให้เครดิตไว้ใน `docs/thai-review.md`

และเราใช้เพื่อ **ยืนยัน** คำแปลของเราเอง ไม่ได้คัดลอกพจนานุกรมมาทั้งชุด
