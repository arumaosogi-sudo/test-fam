## เส้นทางสั้นที่สุดไปสู่ "เดโมที่จับต้องได้" (แนะนำเริ่มจากนี่)

ถ้าเลือก D3 = (ก) เดโมก่อน ลำดับคือ:

```
T001 → T003 → T004 → T005 → T006 → T007
  → T101 → T102 → T103 → T104 → T109
  → T106 (60 คำพอสำหรับเดโม) → T205 → T107 → T108
  → T201 (จับคู่) → T202 (เติมคำ) → T203 (ภาพ-คำ)
  → T301 → T302 (เสียงอ่าน) → T204 (ฟัง-เลือก)
  → T211 → T212 → T213 → T214 (แชทแบบพิมพ์)
  → T304 → T305 → T311 (แชทด้วยเสียง)
  → T607 (deploy ให้คนอื่นลองได้)
```

ได้ของที่ **เล่นได้ครบ 5 โหมด + แชทด้วยเสียง** โดยยังไม่ต้องมี DB/login
จากนั้นค่อยต่อ E6 (บัญชี/ครู) และ E5 (โหมดเพิ่ม) ตามที่คุณสั่ง
